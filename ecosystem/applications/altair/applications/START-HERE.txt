```text
ALTAIR PLATFORM - START HERE
============================

1. Install Node.js 20+.
2. Open this project folder in VS Code.
3. Run:
     npm install
4. Start the complete application:
     npm run dev:all
5. Open:
     http://localhost:5173

Demo login:
  Email: admin@altair.local
  Password: configure locally with ALTAIR_DEMO_PASSWORD

IMPORTANT:
- This version uses demo execution mode by default, so external integrations do not need private credentials.
- Keep the actual demo password in your local environment and do not commit it to GitHub.
- The added feature actions are interactive: create forms add records, Run/Run now starts workflow actions when a matching workflow exists, Review/Resolve changes state, duplicate/delete mutate lists, and exports download CSV files.
- Server/API tests can be run with:
     npm test
```
