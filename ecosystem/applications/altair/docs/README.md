# Documentation

This directory contains Altair's technical documentation, user guides,
onboarding material, standards, references, and supporting documents.

## Ownership

Documentation is maintained by the assigned Knowledge Management and
Documentation Owner and coordinated by the Engineering Lead.

## Change approval

Documentation changes require Team Lead review. Changes affecting architecture,
governance, or shared standards also require Tech Lead approval.
