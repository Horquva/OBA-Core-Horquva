## Integration Boundaries

Castor connects with:

| Platform | What Castor gets from it |
|---|---|
| OBA (Organizational Brain) | Intelligence, knowledge, reasoning, memory |
| Sentinel | Identity, authentication, security, trust |
| Vega | Quality standards, organizational identity |
| Altair | Operational systems data |
| Arcturus | Simulation capabilities |
| Antares | Decentralized governance |

Castor does NOT own these. It consumes them through defined APIs.
