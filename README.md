## 📖 Mission Overview
Welcome to the core repository for the **Simulation Engineering Governance Platform**. This platform is the architectural foundation of Arcturus (Horquva's Synthetic Enterprise Platform). It enforces engineering standards, validates simulation logic, and ensures that every piece of the synthetic enterprise remains constitutionally aligned.

Our goal is to build an ecosystem where organizational simulations are scientifically validated, reproducible, and seamlessly integrated.

## 🛠️ Technology Stack
This repository utilizes a modern, high-performance frontend architecture:
* **Core Framework:** React 18

* **Language:** TypeScript
* **Styling:** Tailwind CSS

---

## 🏗️ Repository Architecture
We follow a strict, standardized folder structure to maintain predictability across the platform. Do not deviate from this layout:

* 📁 **`src/`** — Core application logic, React components, and domain models.
* 📁 **`tests/`** — Automated test suites (Unit, Integration, E2E).
* 📁 **`docs/`** — Technical documentation, API specs, and Architecture Decision Records (ADRs).
* 📁 **`config/`** — Environment variables, Tailwind config, and Vite settings.
* 📁 **`scripts/`** — Automation, setup, and CI/CD helper scripts.
* 📁 **`assets/`** — Static resources, fonts, and baseline dataset templates.
* 📁 **`.github/`** — Pull request templates and GitHub Actions workflows.
