PART 1: What Is WOBA
WOBA is the Web Organizational Brain Assistant. It is the conversational layer that lets anyone ask questions about Horquva in normal language and receive grounded answers drawn from Horquva's organizational knowledge.
A person does not need to know where information is stored, which document contains it, or which system holds it. They ask. WOBA understands the question, retrieves what is relevant, grounds the answer in what it actually found, and responds in plain language. When a source exists, WOBA shows it.
WOBA is not a chatbot in the conventional sense. A chatbot generates responses from a model. WOBA retrieves from organizational knowledge, grounds the response in what it retrieved, and cites the source when one exists. The difference is the difference between a system that sounds confident and a system that is actually backed by evidence.
The flow is simple:
Question → Understanding → Retrieval → Grounding → Answer → Sources → Follow-up
WOBA continues the conversation. A person can ask a question, ask a follow-up, ask for a simpler explanation, ask for the source, and keep going. WOBA maintains context across the conversation. It behaves like someone who knows the material, not like a search box that resets after every query.
The most important thing WOBA does is also the least visible. When it does not know something, it says so. It does not fabricate. It does not guess. It does not present unsupported claims as fact. The value of WOBA is not that it always has an answer. The value is that when it gives an answer, the answer is grounded.
WOBA is a system you can talk to in normal language to understand Horquva.
